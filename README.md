# Веб-проектирование · подготовка к экзамену

Учебное Vue-приложение для дизайнеров: два экзаменационных блока, карточки и интерактивные справочники HTML, CSS и SVG.

## Возможности

- 28 экзаменационных вопросов: 26 кратких конспектов и две свободные темы.
- Колоды по HTML-семантике, CSS, SVG и определениям; режимы «Все», «Повторить незнакомые» и «Ещё не изучены».
- Продолжение занятия с сохранённой карточки.
- Тренировка одного блока или смешанного билета с отдельной самооценкой каждого вопроса.
- HTML-дерево с подсветкой; SVG-схема; лаборатории Position, Flexbox, Grid и единиц.
- Мобильные настройки в bottom-sheet, клавиатурное управление и уменьшение анимаций.
- Общие определения в `src/data/concepts.js`.
- Прогресс в `webdesign_progress_v1`; предыдущие записи веб-проекта переносятся автоматически.

## Запуск и проверки

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## Структура

- `src/data/` — определения, экзаменационные темы и данные справочников.
- `src/views/` — страницы приложения.
- `src/components/` — интерфейс и интерактивные лаборатории.
- `src/store/webProgress.js` — прогресс занятий.
- `src/utils/webProgress.js` — проверка, миграция и сохранение данных.
- `scripts/*.test.mjs` — проверки контента и прогресса.

`base` в `vite.config.js` соответствует репозиторию `ITMO_WebDesign_prepare`.
Публикация выполняется пользователем через `npm run deploy` в ветку `gh-pages`.
В Settings → Pages источником должна быть эта ветка.

Сайт: https://mohonovproduction.github.io/ITMO_WebDesign_prepare/
