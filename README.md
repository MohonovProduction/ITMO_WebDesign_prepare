# Веб-проектирование · подготовка к экзамену

SPA-тренажёр для экзамена по веб-проектированию ИТМО. Проект создан как независимая копия тренажёра по математической статистике: исходный репозиторий не изменяется.

## Первый этап

- Созданы два независимых трека экзамена: «Технология и реализация» и «UX/UI и проектирование».
- Внесены все 28 вопросов: 17 в техническом блоке и 11 в UX/UI-блоке.
- Добавлены главная страница, карта экзамена и фильтруемый список тем.
- Для каждой темы зафиксирован шаблон будущего устного ответа: определение → цель → устройство/процесс → пример → ошибки и связи.

## Следующие этапы

1. Наполнить карточки тем теорией и примерами из лекций.
2. Создать карточки для повторения и режим тренировки устного ответа.
3. Реализовать два пробных экзамена и смешанный билет.
4. Подключить раздельный прогресс по блокам и публикацию на GitHub Pages.

## Локальный запуск

```bash
npm install
npm run dev
npm run build
```

При создании GitHub-репозитория с именем, отличным от `ITMO_WebDesign_prepare`, измените `base` в `vite.config.js`.
