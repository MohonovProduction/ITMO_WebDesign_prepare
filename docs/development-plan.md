# План разработки

## 0. Основа проекта — готово

- Новый репозиторий и GitHub remote.
- Vue/Vite-каркас, два экзаменационных трека, 28 вопросов и навигация.

## 1. Контентный фундамент — в работе

1. Зафиксировать единый формат темы: определение, задача, устройство/этапы, пример, ошибки, связи.
2. Собрать обязательные колоды карточек:
   - семантические HTML-теги;
   - SVG: устройство, `viewBox`, способы вставки и интерактивность;
   - определения из конспектов: UX/UI, сайт, исследования, артефакты проектирования.
3. У каждой карточки хранить привязку к экзаменационному вопросу и треку.
4. Наполнить первые развёрнутые темы технического и UX/UI-блоков.

## 2. Учебные механики

1. Добавить сохранение статуса «знаю / повторить» по отдельным колодам.
2. Дать фильтры: колода, трек, вопрос экзамена, только ошибки.
3. Добавить режим «структура ответа»: пользователь видит вопрос, проговаривает ответ и сверяется с опорным планом.

## 3. Тренировка экзамена

1. Отдельная тренировка технического и UX/UI-вопроса.
2. Смешанный билет: один вопрос из каждого блока.
3. Самооценка по критериям: терминология, логика, пример, связь с продуктом.
4. Экран ошибок и повтор слабых тем.

## 4. Качество и публикация

1. Сверка формулировок с конспектами и материалами преподавателей.
2. Адаптивная проверка: телефон, планшет, десктоп.
3. Accessibility-проход: заголовки, фокус, контраст, клавиатурная навигация.
4. GitHub Pages: production base, deploy, проверка маршрутов и `localStorage`.
